# Analysis of model sloppiness and information imbalance

Julia code associated with "Information Imbalance Characterises the Sensitivity of Parameter Space Directions from Analysis of Model Sloppiness".

The repository covers the six simple models and the original and reduced coral calcification models considered in the paper. The method combines the analysis of model sloppiness with information imbalance to identify sets of parameter-space directions that are important for describing variation in model outputs.

## Requirements

The code requires Julia and the packages imported by the scripts.

## Scripts

| Script | Purpose | Applies to |
| --- | --- | --- |
| `data.jl` | Generates synthetic observation data and saves them in `Data.jld2`. | Six simple models |
| `run_smc.jl` | Uses `Data.jld2` and calls `smc_generic.jl` to obtain posterior parameter samples. The samples are saved in `part_vals.jld`. | Six simple models |
| `smc_generic.jl` | Implements the sequential Monte Carlo (SMC) algorithm used by `run_smc.jl`. | Six simple models |
| `info_imbalance.jl` | Computes the information imbalance values reported for the corresponding model and saves them in `Δ.jld2`. | All models |
| `Plot.jl` | Produces the results figures for the corresponding model. It also calls `Print_Sloppy_Analysis_Table.jl` to generate the table. | All models |
| `Print_Sloppy_Analysis_Table.jl` | Performs the analysis of model sloppiness (`Sloppy_Analysis`) and formats the results as a table. It is called by `Plot.jl`. | All models |

## Six simple models

The same workflow applies to all six simple models. Synthetic observations are generated first and then used to obtain posterior parameter samples through SMC. Information imbalance is computed from these samples and their corresponding model outputs.

Run the following commands in order from the directory containing the relevant scripts:

```bash
julia data.jl
julia run_smc.jl
julia info_imbalance.jl
julia Plot.jl
```

The helper scripts `smc_generic.jl` and `Print_Sloppy_Analysis_Table.jl` are called automatically.

## Coral calcification models

The coral application considers the original 20-parameter model and the reduced 12-parameter model. The observed data and posterior parameter samples are taken from Vollert et al. (2023). The existing posterior samples are used directly.

Model outputs for the synthetic prediction scenarios were generated by Yihan Liu using Sarah Vollert's code. These outputs are stored in the following files:

| File | Contents |
| --- | --- |
| `Y_prediction_R.mat` | Synthetic prediction outputs for the reduced model. |
| `Y_prediction_O.mat` | Synthetic prediction outputs for the original model. |

The coral application uses `info_imbalance.jl`, `Plot.jl` and `Print_Sloppy_Analysis_Table.jl`. Ensure that the observed data, posterior samples and prediction files are available at the paths used by the code.

Run the following commands in order from the directory containing the coral scripts:

```bash
julia info_imbalance.jl
julia Plot.jl
```

The helper script `Print_Sloppy_Analysis_Table.jl` is called automatically by `Plot.jl`.
