# Analysis of model sloppiness and information imbalance

Julia code associated with "Information Imbalance Characterises the Sensitivity of Parameter Space Directions from Analysis of Model Sloppiness".

The method combines the analysis of model sloppiness with information imbalance to identify sets of parameter-space directions that are important for describing variation in model outputs. This repository contains code for six simple models and the original and reduced coral calcification models.

## Model folders

Each model has its own folder. `Main` denotes an example in the main text, and `SI` denotes an example in the Supplementary Information.

| Folder | Model |
| --- | --- |
| `Non_Sloppy_Main/` | Non-sloppy model in the main text. |
| `Sloppy_Main/` | Sloppy model in the main text. |
| `Non_Sloppy_SI_1/` | First non-sloppy model in the SI. |
| `Non_Sloppy_SI_2/` | Second non-sloppy model in the SI. |
| `Sloppy_SI_1/` | First sloppy model in the SI. |
| `Sloppy_SI_2/` | Second sloppy model in the SI. |
| `Coral_Original/` | Original 20-parameter coral calcification model. |
| `Coral_Reduced/` | Reduced 12-parameter coral calcification model. |

## Requirements

The code requires Julia and the packages imported by the scripts. Run the analysis from the folder for the model you want to examine.

## Script descriptions

The table below summarises the scripts used in each workflow.

| Script | Purpose | Applies to |
| --- | --- | --- |
| `data.jl` | Generates synthetic observation data and saves them in `Data.jld2`. | Six simple models |
| `run_smc.jl` | Uses `Data.jld2` and calls `smc_generic.jl` to obtain posterior parameter samples. The samples are saved in `part_vals.jld`. | Six simple models |
| `smc_generic.jl` | Implements the sequential Monte Carlo (SMC) algorithm used by `run_smc.jl`. | Six simple models |
| `info_imbalance.jl` | Computes the information imbalance values reported for the corresponding model and saves them in `Δ.jld2`. | All models |
| `Plot.jl` | Produces the results figures for the corresponding model. It also calls `Print_Sloppy_Analysis_Table.jl` to generate the table. | All models |
| `Print_Sloppy_Analysis_Table.jl` | Performs the analysis of model sloppiness (`Sloppy_Analysis`) and formats the results as a table. It is called by `Plot.jl`. | All models |

## Six simple models

All six simple model folders use the same workflow:

1. Generate synthetic observations with `data.jl`.
2. Obtain posterior parameter samples with `run_smc.jl`.
3. Compute information imbalance with `info_imbalance.jl`.
4. Produce the figures and table with `Plot.jl`.

For example, starting from the repository root:

```bash
cd Non_Sloppy_Main
julia data.jl
julia run_smc.jl
julia info_imbalance.jl
julia Plot.jl
cd ..
```

Replace `Non_Sloppy_Main` with the folder for the simple model you want to analyse. The helper scripts `smc_generic.jl` and `Print_Sloppy_Analysis_Table.jl` are called automatically.

## Coral calcification models

The coral models use observed data and posterior parameter samples from Vollert et al. (2023). These existing posterior samples are used directly in the analysis.

Model outputs for the synthetic prediction scenarios were generated by Yihan Liu using Sarah Vollert's code. These outputs are stored in the following files:

| File | Contents |
| --- | --- |
| `Y_prediction_O.mat` | Synthetic prediction outputs for the original model analysed in `Coral_Original/`. |
| `Y_prediction_R.mat` | Synthetic prediction outputs for the reduced model analysed in `Coral_Reduced/`. |

Ensure that the observed data, posterior samples and corresponding prediction file are available at the paths used by the code. Then:

1. Compute information imbalance with `info_imbalance.jl`.
2. Produce the figures and table with `Plot.jl`.

For example, starting from the repository root:

```bash
cd Coral_Original
julia info_imbalance.jl
julia Plot.jl
cd ..
```

Use `Coral_Reduced` in place of `Coral_Original` to run the reduced-model analysis. In both folders, `Plot.jl` calls `Print_Sloppy_Analysis_Table.jl` automatically.
